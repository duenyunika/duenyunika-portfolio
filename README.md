Nama Produk

Duen Yunika Personal Portfolio

Website portofolio pribadi yang dibuat untuk memperkenalkan profil, pendidikan, keahlian, dan proyek yang telah dikerjakan oleh Duen Yunika sebagai siswi jurusan Rekayasa Perangkat Lunak (RPL).

Fungsi Utama

Website ini berfungsi sebagai media untuk:

- Menampilkan profil dan informasi singkat tentang pengembang.
- Menampilkan riwayat pendidikan.
- Menampilkan keahlian di bidang pengembangan web dan pengolahan data.
- Menampilkan proyek yang telah dibuat.
- Menyediakan informasi kontak untuk menghubungi pengembang.

Website dibuat dengan tampilan yang bersih, responsif, dan mudah digunakan.

Manfaat bagi Pengguna

Portofolio ini membantu pengguna untuk:

- Mengenal profil dan latar belakang pengembang.
- Melihat kemampuan dan teknologi yang sedang dipelajari.
- Mengetahui proyek yang pernah dikerjakan.
- Mendapatkan informasi kontak pengembang dengan mudah.
- Menjadi media dokumentasi perkembangan kemampuan di bidang Rekayasa Perangkat Lunak.

Teknologi yang Digunakan

- HTML
- CSS
- JavaScript

Cara Instalasi

1. Clone Repository

git clone https://github.com/duenyunika/duenyunika-portfolio.git

2. Masuk ke Folder Project

cd duenyunika-portfolio

3. Jalankan Website

Buka file "index.html" menggunakan browser.

Website juga dapat diakses secara online melalui:

https://duenyunika.github.io/duenyunika-portfolio/
